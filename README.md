# Clinical Numeracy Learning

An interactive, browser-based resource for clinical-numeracy education and revision.

## Workbooks

- Frank — acute heart failure
- Luke — acute asthma
- Mollie — fluid overload in CKD
- Bill — acute upper gastrointestinal bleeding
- Thomas — suspected DKA
- Robert — prolonged convulsive seizure
- Patricia — acute manic episode
- Catherine — suspected urosepsis
- William — ulcerative colitis

## Use

1. Download or clone this repository.
2. Open `index.html` in a current web browser.
3. Choose a workbook and select Learn Mode or Challenge Mode.

No installation, server, account, or internet connection is required once the file is available locally.

## Progress and privacy

The app stores learner progress, answers, and settings locally in the browser using local storage. It does not collect, transmit, or share personal data. Progress is specific to the browser and device being used; clearing browser data removes saved progress.

## Educational-use statement

This resource supports clinical-numeracy education and revision only. It does not provide clinical advice and must not be used to calculate, verify, or make decisions about real patient care or medicine administration.

Always follow local policy, approved medicines information, supervision requirements, escalation procedures, and professional judgement.
